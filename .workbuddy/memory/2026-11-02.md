# 11/02 字体主线（把引擎字体换成 FreeType）

## 已确认的事实
- 游戏文本是 **UTF-8 简体中文**（`e9bb91 e69a97...` = 黑曜骑士），加载 `memorytext_zhhans.dat`（资源是加密的）。
- 引擎字体链路：`GRPX_DrawStringWithFont(text,x,y,enc,fontIdx)` → `SGL_grpDrawStringWithFont` →
  `SGL_grpCreateStringImageInRect` → `SGL_Font_Android::RenderToTextureInRect` → `SGL_RenderFontToAlphaImageInRect`。
  最后一层走 Android Paint，壳里是空的 → **真机 Data Abort @ 0**（crash report: `RenderFontToAlphaImageInRect+0x180`）。
- `SGL_Font_Android::GetStringWidth` 内部调 `SGL_GetTextSize`（同一条坏路径）→ 引擎排版宽度全错，
  属性栏数值被推出面板。`SGL_GetTextSizeInRect` 同理。

## 修法
1. `text.c` 改用 `PlSharedFontType_ChineseSimplified`（原来用 Standard=日文字体，缺简体字形=乱码）。
2. hook **`GRPX_DrawStringWithFont`**（带 fontIndex，能拿到字号）+ `SGL_grpDrawStringWithFont`，
   用 FreeType 画：`text_draw_engine()`，在**引擎当前矩阵**下画四边形，不改投影。
3. `SGL_RenderFontToAlphaImageInRect(Ex)` 空实现，防止任何残留路径再崩。
4. hook `GetStringWidth` / `GetStringWidthInRect` / `SGL_GetTextSizeInRect` 返回 FreeType 宽度，
   让排版和绘制一致（这是属性栏数值位置的根因）。
5. 字号：引擎各档 line height 不一致（标题 26 / 描述 39），统一用固定 `text_px=20`。
6. 折行：引擎给的是一整行（newlines=0），`text_wrap_w=470` 自己断行，
   并用 `wrap_extra` 把同一段后续行整体下移，避免和引擎固定 y 的下一行相撞。
7. `nx_TouchHandle_Event` 的 root 替换收紧：**只在 root 是空壳（≤1 子控件）时**才换 live，
   否则会把别的界面树拿去做命中测试 → 点职业被派发成设置按钮（"随机弹环境设置"）。

## 21:5x 当前卡点：防篡改校验的响应体为空

引擎开机请求 `http://s.com2us.net/common/protect/check.c2s`（Com2uS 防篡改）。
`netHttpOpenEx` 现在返回成功（前两次），`netHttpConnectEx` 也成功，
但**响应体长度为 0**，引擎判定失败 → 弹「连接出错。请稍后再试」，
并卡住后续 profile 加载（背包空、属性 0、存档读不出）。

关键日志：
```
net: open #0 kind=O url=''          ← URL 是 Java String 对象，str_of() 读不出
JNI+: netHttpConnectEx(I)I
gl: str bytes e8bf9e e68ea5 e587ba e99499 ... = "连接出错。请稍后再试"
```

`netHttpOpenEx` 的 URL 参数 kind='O'，`str_of()` 返回空串，所以没法按 URL 区分请求——
目前按"开机前两次调用"放行。

**下一步**：实现 `netHttpGetResponseBody`（返回 byte[]）给一个最小合法响应体，
或在引擎的解析代码里看它期望什么格式。若这条路成本太高，
可考虑让引擎走"离线"分支：校验失败但**不弹框、不阻塞**（拦截 UIPopupMsg 的创建）。
