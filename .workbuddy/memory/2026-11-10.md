## 改法
- `input.h` 新增 `NAV_SHAPE_ELLIPSE`。
- `main.c` 新增 `nav_add_title()` / `nav_title_art()`：标题页 item 的高亮
  rect 内缩到 **命中框宽度的 92%**（可见椭圆主体，排除两端尖角），高度按
  资产实测的 `w/4.63` 算并居中；`tx/ty` 保持**原控件中心**不变（缩小高亮
  绝不能把点击也挪走）。
- `nav_gold_cursor()`：ELLIPSE 走椭圆采样但 N 从 72 提到 **220**（扁椭圆
  用 72 点会变成离散圆点），并换一组更紧的 halo `{2,1,0}` px / `{4,3,2}` px，
  避免 5px 外扩又把框撑大。
- 其余页面（设置 / 存档 / 职业）的形状与 band 完全不变。

## 13:2x 三条修正（能力点 A / 弹框导航范围 / 标题药丸）
- **①`能力点 +` 按 A 现在真的点击**：`input.c` 的 `NAV_K_STAT_ENTER` 分支原来只把
  `nav_mode` 改成 `NAV_STAT`，引擎根本没收过触摸 → 页面不动，只有高亮掉到属性行。
  现在先 `nav_tap(it)` 走公共触摸路径，再置 `nav_stat_hold=1` + `nav_dirty=1`。
  `input_set_nav()` 的 dirty 分支在 `nav_stat_hold` 时保持 `NAV_STAT`（否则重扫会把
  模式打回 BODY）；`stat_mode` 变 0、按 B、换页、关页都会清 hold。
- **②弹框只收最前一层**（`main.c`）：引擎把详情面板压在**完全相同 rect** 上
  （本 build 是 `173,133 409x431`，物品页 snapshot 里 1459/1479/1500 三层同 rect）。
  新增 `nav_top_layer()`（同父同 rect 的兄弟 → 取**索引最大**那个，即最上层）与
  `nav_find_top_layer()`（全树找第一处堆叠）；`nav_scan()` 有堆叠时只收集该子树，
  其余（左列 104x113、右侧说明栏 1507/1508/1509）全部不参与光标移动。
  另加 `nav_is_layout_strip()`：rect 恰等于子控件并集的纯排版条（`235,243 286x42`，
  内含 3 个 82x42 动作按钮）不作为光标停靠点。
  ⚠️ 不能用"兄弟矩形互相包含"判遮挡：右侧说明栏 `625,133 409x431` 就被
  `88,133 1137x431` 包住但它是可见的，只有**完全同 rect** 才代表层叠。
- **③标题高亮改药丸**：`nav_add_title()` 的 shape 由 `NAV_SHAPE_ELLIPSE` 改为
  `NAV_SHAPE_PILL`（直边 + R=H/2 半圆端）；`nav_gold_cursor()` 的 k 拆成
  `kx=w/1137`、`ky=h/640` 分别缩放（原来单一 k 在非 16:9 配置下横纵不一致）；
  扁长控件（`bw > bh*3`）用窄 band `{2,1,0}`；圆弧采样 8 段 → 12 段，
  直边/弧段都加了 `W-2R>0` / `H-2R>0` 保护。
- 编译 `python build.py` 通过，NRO md5 `e4cb085727f0e7e01cbb86e67d4cd420`，
  build/dist/Eden 三处一致；存档只读核对与部署前完全一致
  （18 文件 / 3,079,822 字节 / 目录 md5 `7b4fb848…` / config.ini `b3076640…`）。
