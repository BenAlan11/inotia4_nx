   日志 `ui: shop pre-dispatch skipped, synthesizer page at (x,y)`。
2. 新增合成页识别与一次性诊断：
   - 解析 `UIMix_StuffItemControlEventProc` / `UIMix_InvenItemControlEventProc` /

   - 面板归属改成**两条独立证据**：`desc_page_frame` 30 帧内 **或**

4. `input.c`：每次真实手指按下打一行 `input: finger press (sx,sy) screen, hud block N`，

## 18:55 最左插槽只有左上偏中能点 —— 真凶是虚拟摇杆的触摸否决，不是控件 rect

用户：「最左插槽只有左上偏中能点」。

### 取证（sdmc/debug.log，18:42–18:46，build 18:39，docked 1920x1080）
- 上一轮的 `mix_probe_node()` **一次都没命中**（日志无 `mix: ----`、无 `mix: ev`），
  所以 `mix_page_frame` 恒 0 → `shop_button_pre_dispatch()` 的合成页豁免从来没生效。
  原因：UIMix 的控件树**不是**场景 root 的子节点，扫 root 永远找不到 stuff proc。
  合成页控件树的入口是模块全局 **`0x2b72b0`**（`UIMix_CreateMainControl` 写入，
  `UIMix_Exit` 清零）；`0x2b72c0` 是背包容器，`0x2b72d0/0x2b72d8` 是槽数组/槽数，
  `0x2b7208` 是 UIMix state。
- 用户点击的引擎坐标集中在 x 200–510 / y 370–440（三个孔那一行）。
  日志配对：
  - `input: finger press (344,633) screen, hud block 0` → 通过
  - `input: finger press (346,640) screen, hud block 1` + `touch in HUD rect 3 swallowed`
    → 被吞。HUD rect 3 = `HUD_DPAD` (id 21, 引擎 10,388 252x252)
    → 屏幕 x 13..446 / y 651..1084。反算到引擎：**x<264 且 y>386 全被吞**。
- 三个孔的 x 大致 194 / 310 / 426（间距 116、宽 74）。最左孔 157..231 与
  「x<264 且 y>386」相交，只剩**左上角**可点 —— 与用户描述逐字吻合。
  中/右孔 x>264，不受影响。

### 改动
1. `src/input.c` 新增 `input_set_page_rect(x,y,w,h,enabled)` + `hud_page_hit()`；
   `hud_touch_blocked()` 最前面判断「落点在已发布的模态页面上」→ 直接放行，
   日志 `input: page touch passed (x,y)`。页面矩形用引擎布局单位，与 HUD rect 同套换算。
2. `src/main.c` 新增 `mix_container_obj()`（读 `vb+0x2b72b0`，非空即合成页）、
   `mix_tick()`（hud_tick 每帧调用）、`mix_dump_container()`：
   - 合成页上：`mix_page_frame = g_frame_no`（shop 预分发自动豁免）+ 发布整屏页面
     矩形 (0,0,1137,640) 到 input 层 → 摇杆不再吞插槽；
   - 首帧打印 `mix: page up, container %p` 并 dump 容器子树
     （`mix: ---- socket container %p rect x,y wxh, N child(s)`），
     用于下一轮核对三个槽的真实 rect；
   - 页面关闭打印 `mix: page down` 并撤销豁免。
3. `mix_probe_node()` 的 proc 扫描保留作兜底，但不再承担页面识别。

### 教训
**「控件 rect 对不上可见图形」这种症状，先查输入层有没有在到引擎之前就把手指吞掉**
（HUD rect / 白名单 / 仓库盾牌），再看引擎控件 rect。日志里
`input: finger press ... hud block N` 就是为此加的，这次它直接给出了答案。
另一个通用教训：**移植层自己的「页面识别」如果靠扫 root 找 proc，先确认那棵控件树
真的挂在 root 下**；UIMix 这种模块全局挂载的树要按全局指针认页。
