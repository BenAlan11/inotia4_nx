需要注意的运行时线索
--------------------------------------------------------------------
- 需要 nativeSetClass：引擎靠它拿到 Java 侧的 jmethodID 表，之后用
  CallStaticVoidMethod / CallIntMethod 大量回调。JNI 表要按它请求的
  类名/方法名逐个应答，缺一个就可能空指针。
- GetPackageName 出现在 .so 字符串里：包名要如实返回，否则资源路径错。
- CS_mdaSound*（Create/Play/Stop/Pause/Resume/SetVolume/GetVolume/
  Prepare/Destroy）→ Java SoundPool / MediaPlayer，需自建 Ogg 后端。
- CS_knlGetTouchCount → 触摸输入由外部合成。
- 引擎符号前缀 GEM_LIB_*、CS_*、Ino3_*，源码路径
  jni/gamesrc/Source/{Ino3_UI.c, s_character.c, GEM_LIB_Logger.c, ...}
